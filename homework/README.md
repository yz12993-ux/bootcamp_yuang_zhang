# Bootcamp Homework Submissions

This folder contains completed submissions for the pre-class setup and Stages 01-12.

- `homework0/`: Python/Jupyter setup check
- `homework1/`: problem framing and stakeholder context
- `homework2/`: reproducible project tooling and environment configuration
- `homework3/`: Python, NumPy, and pandas dataset exploration
- `homework04/`: API acquisition, table scraping, validation, and raw snapshots
- `homework05/`: environment-driven CSV/Parquet storage and reusable IO utilities
- `homework06/`: modular missing-data cleaning and normalization
- `homework07/`: outlier detection, treatment sensitivity, and risk reflection
- `homework08/`: complete EDA, time-series read, and reusable EDA helper
- `homework09/`: EDA-linked feature engineering and categorical encoding
- `homework10a/`: linear-regression fit, diagnostics, and trust assessment
- `homework10b/`: leakage-aware time-series/classification pipelines and baselines
- `homework11/`: bootstrap uncertainty, scenario sensitivity, and subgroup risk
- `homework12/`: stakeholder-ready Markdown report, polished charts, and delivery notes

Each stage is self-contained and should be run from its own stage directory with the `bootcamp_env` Python/Jupyter environment. The original official starter notebooks and homework sheets remain unchanged under `Homeworks - Stages00-13 ✔/`.
