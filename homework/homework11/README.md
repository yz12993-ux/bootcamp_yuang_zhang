# Homework 11 - Evaluation and Risk Communication

The executed notebook generates a seeded heavy-tailed regression dataset, compares an analytic Gaussian mean-response interval with a 1,000-replication case-bootstrap interval, bootstraps MAE, compares mean/median/drop scenarios, and diagnoses residuals across segments. Helper functions live in `src/evaluation.py`; tables and figures are saved under `data/processed/` and `reports/images/`.
