# Stage 03 - Python Fundamentals

This submission explores `data/raw/starter_data.csv` with NumPy and pandas. Run `notebooks/hw03_python_fundamentals.ipynb` from top to bottom to inspect the data, calculate descriptive statistics, compare categories, save the processed summary, and create the bonus chart.

## Outputs

- `data/processed/summary.csv` - category-level count, total, mean, minimum, and maximum
- `data/processed/value_by_category.png` - bonus chart of total values by category
- `src/utils.py` - reusable `get_summary_stats` function
