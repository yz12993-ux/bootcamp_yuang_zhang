# Stage 12 Report Delivery Notes

**Audience:** an investment committee deciding whether a prototype strategy is ready for a limited pilot or full allocation.

**Chosen format:** written Markdown report. This format keeps the decision summary, chart interpretations, assumptions, and sensitivity evidence in one version-controlled file while the executed notebook remains the technical audit trail.

**Why it fits:** committee readers can skim the Executive Summary and decision implication first, then inspect three self-contained PNG figures. The report clearly labels the data as synthetic and avoids implying that a 12-month exercise is an investable forecast.

Run `homework12_results-reporting-delivery-design_submission.ipynb` from the `homework12/` directory to regenerate all tables, images, and the final report.
